개인정보처리방침

사회혁신교육원 사회적협동조합(이하 "교육원")은 내부 업무 도구 gws(구글 워크스페이스 자료 이관 도구)를 운영하면서 아래와 같이 개인정보를 처리합니다.

시행일: 2026년 10월 2일

1. gws 가 무엇인가

gws 는 교육원이 보유한 구글 계정의 자료를 교육원 자체 서버로 내려받아 보관·정리하기 위해 만든 내부 전용 명령줄 도구입니다. 외부에 공개된 서비스가 아니며, 교육원 임직원만 사용합니다. 회원가입·광고·결제 기능이 없습니다.

2. 접근하는 Google 사용자 데이터

이용자가 Google 로그인 화면에서 직접 동의한 범위에서만 접근합니다.

범위접근 내용이용 목적
Google Drive파일 목록·속성·내용자체 서버로 자료 내려받기, 중복 확인
Google Docs / Sheets문서·스프레드시트 내용문서 형식(docx·xlsx)으로 변환해 보관
Gmail메일 목록·내용, 임시보관함 작성업무 메일 확인 및 초안 작성
Google Calendar일정 조회·등록업무 일정 확인 및 등록
계정 이메일 주소로그인한 계정 식별여러 계정을 구분해 저장

3. 저장과 보관

  • 내려받은 자료는 교육원이 직접 운영하는 국내 서버의 저장장치에 보관합니다. 외부 클라우드에 올리지 않습니다.
  • 접근 토큰은 해당 서버 안에만 파일로 저장하며, 운영체제 권한(소유자 전용)으로 보호합니다.
  • 보관 기간은 교육원의 기록물 보존 규정과 보조사업 정산·감사에 필요한 기간을 따릅니다.

4. 제3자 제공

제공하지 않습니다. 판매·대여·광고 활용·인공지능 학습 데이터로의 이용이 일절 없습니다. 법령에 따른 수사기관의 적법한 요청이 있는 경우에만 그 범위에서 응합니다.

5. Google API Services User Data Policy 준수

gws 가 Google API 로부터 받은 정보의 이용과 다른 앱으로의 전송은 Google API Services User Data Policy 를 따르며, 여기에는 Limited Use 요건이 포함됩니다. 받은 데이터는 위 2항에 적은 목적 외에 사용하지 않습니다.

6. 이용자의 권리

  • 언제든지 Google 계정 권한 관리에서 gws 의 접근 권한을 철회할 수 있습니다. 철회 즉시 gws 는 해당 계정에 접근하지 못합니다.
  • 이미 내려받은 자료의 삭제를 원하시면 아래 연락처로 요청하실 수 있습니다. 법령상 보존 의무가 있는 자료는 그 기간 경과 후 파기합니다.
